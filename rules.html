🐾 Главные правила кормления 1. Кормим только по расписанию и отмеренными порциями (на весах, в граммах). Просит есть не по расписанию — не кормим. 2. Кошки едят одновременно, но в разных комнатах, дверь закрыта. Через 20–30 минут остатки убираем — Старшая не должна доедать за Младшей. 3. Корм для котят — только Младшей. Старшей — только её корм для стерилизованных. 4. Перед тем как кормить, загляни в /today: если уже покормили — второй раз не кормим. 5. Вода свежая всегда: меняем утром и вечером, миски моем каждый день. Молоко не даём — от него болит живот. 6. Лакомства — не больше 10% нормы, и только с разрешения родителей.
