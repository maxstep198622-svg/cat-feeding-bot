# 🐾 Кошачий бот: напоминания о кормлении и воде

Telegram-бот для семьи: в нужное время напоминает тому, кто дома, покормить кошек и поменять воду. Подсказывает, сколько грамм класть каждой, и следит, чтобы кормление не забыли и не сделали дважды.

Экспертный разбор кормления — в [ПЛАН_КОРМЛЕНИЯ.md](ПЛАН_КОРМЛЕНИЯ.md). Само расписание задаётся в [config.example.toml](config.example.toml).

## Что умеет

- **Напоминает тому, кто дома.** У каждого кормления есть ответственный и запасной. Утром это взрослый, после школы — Тася, вечером — Таня.
- **Показывает граммы для каждой кошки.** Они считаются по весу кошки, её возрасту и калорийности корма с упаковки. Ниже 10 г бот пишет с точностью до 0,1 г.
- **Пишет короткую инструкцию для ребёнка:** куда закрыть котёнка, когда убрать миски.
- **Кнопки под напоминанием:**
  - «✅ Готово» — нажимать, как только миски поставлены. Через 30 минут бот сам напомнит убрать остатки и спросит, всё ли съели.
  - «⏰ Через 10 мин» — бот напомнит позже.
  - «🙅 Не могу» — задача уходит следующему, кто может её сделать.
- **Кнопка «🏠 Я дома».** Обед приходит Тасе сразу, как она нажмёт эту кнопку. Если забудет — в обычное время её прихода из школы (его можно задать по дням недели). Родители видят «Тася дома (14:05)».
- **Тревожная кнопка «🚨 Что-то не так».** Ребёнок выбирает кошку и что случилось (вялая, не ест, рвота…), и родители сразу получают сообщение.
- **Следит за аппетитом.** Если котёнок оставил много корма два кормления подряд, родители получают предупреждение.
- **Защищает от двойного кормления.** Если кто-то уже отметил кормление, второй человек увидит «Уже покормили: Таня, 18:05. Второй раз кормить не нужно».
- **Сообщает родителям о пропуске.** Если через 30 минут кормление не отмечено, приходит сообщение запасному и родителям. Через 2,5 часа оно засчитывается пропущенным.
- **Присылает родителям вечернюю сводку:** кто что сделал и что пропущено, плюс сколько задач Тася сделала за неделю.
- **Помнит возрастные события.** В 4 месяца напомнит о стерилизации, в 6 предложит сократить число кормлений, в год — перейти на корм для взрослых. После стерилизации сам уменьшит норму.
- **Пересчитывает порции по весу.** `/weight Младшая 1.6` записывает вес, и порции меняются сразу.
- **Поддерживает режимы дня:** будни, выходной, каникулы. Праздники и каникулы задаются датами, разовую смену режима делает родитель через `/mode`.

## Запуск за 10 минут

1. **Создайте бота.** В Telegram напишите [@BotFather](https://t.me/BotFather): `/newbot`, затем имя, затем логин. Он пришлёт токен вида `123456:ABC...`.
2. **Подготовьте конфиг:**
   ```bash
   cd cat-feeding-bot
   cp config.example.toml config.toml
   ```
   В `config.toml` проверьте:
   - вес кошек и даты рождения;
   - корма и их калорийность (на упаковке «Энергетическая ценность … ккал/100 г»);
   - время прихода Таси по дням недели;
   - семейный код `join_code`: латиница и цифры, без пробелов.
3. **Проверьте расписание без Telegram:**
   ```bash
   python3 -m venv .venv && . .venv/bin/activate
   pip install -r requirements.txt
   python -m catbot --check                  # план на сегодня, все напоминания и граммы
   python -m catbot --check --date 2026-10-17   # то же для субботы
   ```
4. **Запустите бота:**
   ```bash
   export CATBOT_TOKEN=123456:ABC...
   python -m catbot
   ```
5. **Подключите семью.** Каждый открывает бота, нажимает «Старт», вводит семейный код и выбирает себя: Папа, Таня или Тася. Можно отправить ссылку `https://t.me/<логин_бота>?start=<код>` — тогда код вводить не нужно.

Бот должен работать постоянно. Подойдёт домашний компьютер, Raspberry Pi или недорогой VPS.

- **Docker:**
  ```bash
  echo "CATBOT_TOKEN=123456:ABC..." > .env
  docker compose up -d --build
  ```
- **systemd:** готовый сервис лежит в [deploy/catbot.service](deploy/catbot.service).

## Команды

| Команда | Что делает |
|---|---|
| `🏠 Я дома`, `📋 Сегодня`, `🚨 Что-то не так` | Кнопки внизу экрана (то же самое — `/home`, `/today`, `/alert`) |
| `/today` | План на сегодня: ✅ сделано, ⏳ ещё не время, 🔔 ждём, ❌ пропущено. Кнопками можно отметить кормление заранее. |
| `/ration` | Суточная норма каждой кошки и граммы на каждое кормление |
| `/weight Младшая 1.6` | Записать вес. Можно в граммах: `/weight Младшая 1600` |
| `/plan` | Короткие правила кормления |
| `/mode` | Режим на сегодня или завтра: будни, выходной, каникулы, авто (только родители) |
| `/pause`, `/resume` | Пауза напоминаний, например на время отъезда (только родители) |
| `/help` | Справка |

## Как настроить под себя

Всё настраивается в `config.toml`, комментарии внутри файла. Основное:

- **Время по дням недели.** `time_by_day = { tue = "15:30" }` — во вторник Тася приходит позже.
- **Кто делает.** `primary` — ответственный, `backup` — запасной. Если запасной не отвечает, задача уходит родителям.
- **Порции.** `share` — доля суточной нормы кошки на это кормление. За день доли каждой кошки должны давать 100%, это проверяет `--check`.
- **Один и тот же приём в разных режимах.** У него одинаковый ключ `meal`, например завтрак будней и завтрак выходного — `meal = "breakfast"`. Если сменить режим посреди дня, бот поймёт, что этот приём уже дали, и не предложит покормить второй раз. Если время приёма недавно прошло, а его не давали, бот напомнит сразу.
- **Норма от ветеринара.** Если ветеринар назвал точную суточную норму, впишите `daily_kcal`: она важнее расчёта.
- **Стерилизация младшей.** После операции впишите `neutered = true` и `neutered_on = "ГГГГ-ММ-ДД"`.
- **Праздники и каникулы.** Даты задаются в `holidays` и `[[periods]]`.

После правки конфига перезапустите бота.

## Устройство

```
catbot/
  config.py     — чтение и проверка config.toml
  scheduler.py  — расписание и решение «что пора сделать» (без Telegram, покрыто тестами)
  ration.py     — суточная норма (RER × множитель), граммы, возрастные вехи
  storage.py    — SQLite: журнал кормлений, вес, участники, режимы дней
  texts.py      — тексты сообщений
  bot.py        — команды, кнопки, тик раз в 30 секунд
tests/          — тесты логики и сценариев бота на заглушке Telegram
```

Раз в 30 секунд бот проверяет журнал и решает, кому пора написать. Поэтому после перезапуска ничего не теряется: если бот лежал во время кормления, он напомнит сразу после старта.

Тесты:

```bash
pip install -r requirements-dev.txt && python -m pytest -q
```
