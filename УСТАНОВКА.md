# Установка бота «Стефа и Фая» на сервер

Займёт 20–30 минут, один раз. Понадобятся телефон с Telegram и компьютер. На компьютере ничего устанавливать не нужно, только копировать команды.

## Шаг 1. Создайте бота в Telegram (2 минуты)

1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите «Запустить».
2. Отправьте `/newbot`.
3. Имя бота: `Стефа и Фая`.
4. Логин: латиницей и с `bot` на конце, например `stefa_i_faya_bot`. Если логин занят, придумайте другой.
5. BotFather пришлёт **токен** — строку вида `123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw1`. Это пароль от бота: никому его не пересылайте. Он понадобится на шаге 5.

## Шаг 2. Арендуйте сервер (VPS)

**Сервер должен быть за рубежом**, например в Нидерландах, Финляндии или Германии. С российских серверов с 2026 года доступ ботов к Telegram заблокирован, и бот там работать не будет.

Что выбрать при заказе:

| Параметр | Что выбрать |
|---|---|
| Расположение | Нидерланды, Финляндия или Германия — **не Россия** |
| Система | **Ubuntu 24.04** |
| Тариф | самый маленький: 1 ядро, 1 ГБ памяти, 10–20 ГБ диска |
| Цена | обычно 250–500 ₽ в месяц |

Иностранные серверы с оплатой российской картой есть, например, у FirstVDS, HOSTKEY и ProfitServer — цены сверяйте на их сайтах. После оплаты вам пришлют (на почту или в панели управления):
- **IP-адрес** сервера — четыре числа через точку, например `45.67.89.10`;
- **пароль** пользователя `root`.

## Шаг 3. Подключитесь к серверу

**С компьютера на Windows:**
1. Нажмите «Пуск», наберите `PowerShell` и откройте его.
2. Введите (вместо `45.67.89.10` — ваш IP) и нажмите Enter:
   ```
   ssh root@45.67.89.10
   ```
3. Если спросит `Are you sure you want to continue connecting`, напишите `yes` и нажмите Enter.
4. Введите пароль от сервера. **Пока вы его вводите, на экране ничего не появляется — это нормально.** Нажмите Enter.

**С Mac:** то же самое, только вместо PowerShell откройте программу «Терминал».

**С телефона:** установите приложение **Termius**. В нём: «New host», адрес — ваш IP, пользователь — `root`, пароль — от сервера.

Получилось, если появилась строка вида `root@...:~#`. Дальше команды вставляются в это окно: в PowerShell — правой кнопкой мыши, потом Enter.

## Шаг 4. Скачайте бота с GitHub

Проект на GitHub закрытый, поэтому серверу нужно один раз «войти» под вашим аккаунтом.

1. Вставьте и нажмите Enter:
   ```
   apt update && apt install -y gh git
   ```
2. Затем:
   ```
   gh auth login -h github.com -p https -w
   ```
3. На экране появится код из 8 символов, например `ABCD-1234`, и предложение нажать Enter. Нажмите Enter: браузер на сервере не откроется, это нормально.
4. На телефоне или компьютере откройте **https://github.com/login/device**, войдите в GitHub, введите этот код и подтвердите доступ.
5. Вернитесь к серверу и, когда там появится `Logged in as …`, вставьте:
   ```
   gh auth setup-git
   git clone https://github.com/maxstep198622-svg/cat-feeding-bot.git /opt/stefa-i-faya
   ```

## Шаг 5. Установите бота одной командой

```
bash /opt/stefa-i-faya/deploy/install.sh
```

Скрипт попросит токен из шага 1: вставьте его и нажмите Enter. Дальше всё произойдёт само: скрипт проверит связь с Telegram, проверит расписание и запустит бота. Бот будет работать круглосуточно и сам поднимется после перезагрузки сервера.

В конце появится **ссылка-приглашение** вида `https://t.me/stefa_i_faya_bot?start=...` и семейный код. Сохраните их.

## Шаг 6. Подключите семью

Отправьте ссылку-приглашение Тане и Тасе и откройте её сами. Каждый нажимает «Запустить», затем на своё имя: Папа, Таня или Тася. После этого бот присылает напоминания по расписанию.

Проверьте: нажмите в боте «📋 Сегодня» — появится план на день.

## Если что-то пошло не так

- **Скрипт пишет «Сервер не может связаться с Telegram».** Сервер в России. Закажите сервер в другой стране и повторите шаги 3–5.
- **Скрипт пишет «Это не похоже на токен».** Скопируйте токен из сообщения @BotFather целиком и запустите шаг 5 ещё раз.
- **Любая другая ошибка.** Скопируйте текст ошибки и пришлите его Claude.

## Потом: обновление

Когда Claude поменяет расписание или исправит бота, подключитесь к серверу (шаг 3) и выполните:

```
bash /opt/stefa-i-faya/deploy/update.sh
```

Если в новых настройках окажется ошибка, бот не перезапустится и продолжит работать по-старому.

Полезные команды:
- `systemctl status catbot` — работает ли бот (зелёное `active (running)` — да);
- `journalctl -u catbot -n 50` — последние сообщения бота, если нужно разобраться в проблеме.
