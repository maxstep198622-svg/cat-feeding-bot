# Установка бота «Стефа и Фая» на сервер

Займёт 30–40 минут, один раз. Понадобятся телефон с Telegram и компьютер. Удобнее всего делать с компьютера: на нём ничего устанавливать не нужно, только копировать команды.

**Как копировать и вставлять в чёрном окне сервера (PowerShell):**
- вставить — **правая кнопка мыши**;
- скопировать текст из окна — **выделить мышью и нажать правую кнопку**;
- `Ctrl+C` в этом окне не копирует, а прерывает команду.

## Шаг 0. Закройте проект от посторонних (1 минута)

В проекте есть имена семьи и расписание Таси, поэтому он должен быть закрытым.

1. Откройте https://github.com/maxstep198622-svg/cat-feeding-bot/settings.
2. Пролистайте вниз до красного блока **Danger Zone** → **Change visibility** → **Make private** и подтвердите.

Наверху страницы проекта рядом с названием должно быть написано **Private**.

## Шаг 1. Создайте бота в Telegram (2 минуты)

1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите «Запустить».
2. Отправьте `/newbot`.
3. Имя бота: `Стефа и Фая`.
4. Логин: латиницей и с `bot` на конце, например `stefa_i_faya_bot`. Если логин занят, придумайте другой.
5. BotFather пришлёт **токен** — строку вида `123456789:AAHdqTcvCH1vGWJxfSeofSAs0K5PALDsaw1`. Это пароль от бота: никому его не пересылайте.

Переписывать токен вручную не нужно. Откройте этот же чат с @BotFather в Telegram на компьютере (приложение или web.telegram.org) и нажмите на токен — он скопируется.

## Шаг 2. Арендуйте сервер (VPS)

**Сервер должен быть за рубежом**, например в Нидерландах, Финляндии или Германии. С российских серверов с 2026 года доступ ботов к Telegram заблокирован, и бот там работать не будет.

| Параметр | Что выбрать |
|---|---|
| Расположение | Нидерланды, Финляндия или Германия — **не Россия** |
| Система | **Ubuntu 24.04** |
| Тариф | самый маленький: 1 ядро, 1 ГБ памяти, 10–20 ГБ диска |
| Цена | обычно 250–500 ₽ в месяц |

Иностранные серверы с оплатой российской картой есть, например, у FirstVDS и HOSTKEY — актуальные цены сверяйте на их сайтах. После оплаты вам пришлют (на почту или в панели управления):
- **IP-адрес** сервера — четыре числа через точку, например `45.67.89.10`;
- **пароль** пользователя `root`.

Сервер готов через 5–15 минут после оплаты.

## Шаг 3. Подключитесь к серверу

**С компьютера на Windows:**
1. Нажмите «Пуск», наберите `PowerShell` и откройте его.
2. Введите (вместо `45.67.89.10` — ваш IP) и нажмите Enter:
   ```
   ssh root@45.67.89.10
   ```
3. Если спросит `Are you sure you want to continue connecting`, напишите `yes` и нажмите Enter.
4. Когда попросит `password`, скопируйте пароль из письма хостера и вставьте его правой кнопкой мыши. **На экране ничего не появится — это нормально.** Нажмите Enter.

**С Mac:** то же самое, только вместо PowerShell откройте программу «Терминал», а вставляйте через `Cmd+V`.

**С телефона** — запасной вариант:
1. Установите приложение **Termius**. При первом запуске оно попросит создать бесплатную учётную запись по почте. От платной подписки откажитесь — бесплатной хватит.
2. Нажмите «+» → **New Host**:
   - Address — ваш IP;
   - Username — `root`;
   - Password — пароль от сервера.
3. Нажмите на созданный сервер. На вопрос о незнакомом сервере (fingerprint) нажмите **Continue**.

Вставлять команды в Termius: долгое нажатие в окне → **Paste**. Во время установки не сворачивайте Termius надолго.

Получилось, если появилась строка вида `root@...:~#`. Все следующие команды вставляются в это окно.

## Шаг 4. Скачайте бота с GitHub

Сервер получит **ключ только для чтения этого проекта**: он сможет скачивать обновления бота и больше ничего.

1. Вставьте весь блок целиком и нажмите Enter. Если Windows спросит про вставку нескольких строк — нажмите «Вставить всё равно».
   ```
   mkdir -p /root/.ssh && chmod 700 /root/.ssh
   [ -f /root/.ssh/stefa_deploy ] || ssh-keygen -t ed25519 -N "" -C stefa-vps -f /root/.ssh/stefa_deploy -q
   grep -q stefa_deploy /root/.ssh/config 2>/dev/null || printf 'Host github.com\n  IdentityFile /root/.ssh/stefa_deploy\n  StrictHostKeyChecking accept-new\n' >> /root/.ssh/config
   cat /root/.ssh/stefa_deploy.pub
   ```
2. Последней строкой появится ключ, который начинается с `ssh-ed25519` и заканчивается на `stefa-vps`. Скопируйте всю эту строку: выделите мышью и нажмите правую кнопку.
3. Откройте https://github.com/maxstep198622-svg/cat-feeding-bot/settings/keys/new и заполните:
   - Title — `Сервер`;
   - Key — вставьте скопированную строку;
   - галочку **Allow write access не ставьте**.
4. Нажмите **Add key**. GitHub может попросить ваш пароль от GitHub или код подтверждения.
5. Вернитесь к серверу и вставьте:
   ```
   git clone git@github.com:maxstep198622-svg/cat-feeding-bot.git /opt/stefa-i-faya
   ```

Получилось, если в конце нет слов `fatal` или `Permission denied`.

## Шаг 5. Установите бота одной командой

```
bash /opt/stefa-i-faya/deploy/install.sh
```

Скрипт попросит токен из шага 1. Вставьте его (правая кнопка мыши) и нажмите Enter. Дальше всё произойдёт само:
- скрипт поставит нужные программы;
- проверит связь с Telegram и расписание;
- запустит бота.

Бот будет работать круглосуточно и сам поднимется после перезагрузки сервера. Если сервер только что куплен, скрипт может несколько минут писать «Сервер сейчас сам ставит обновления — жду…» — просто подождите.

В конце появится **ссылка-приглашение** вида `https://t.me/stefa_i_faya_bot?start=...` и **семейный код** из 8 знаков. Скопируйте их (выделить мышью → правая кнопка) и сохраните.

## Шаг 6. Подключите семью

Отправьте ссылку-приглашение Тане и Тасе и откройте её сами. Каждый нажимает «Запустить», затем на своё имя: Папа, Таня или Тася. Если ссылка не открывается, найдите бота по логину, нажмите «Запустить» и введите семейный код.

Проверьте: нажмите в боте «📋 Сегодня» — появится план на день. После этого бот сам будет присылать напоминания по расписанию.

## Если что-то пошло не так

- **`Permission denied, please try again` при входе на сервер.** Пароль не подошёл. Скопируйте его из письма заново (без пробела в конце) и вставьте правой кнопкой мыши.
- **`Connection timed out`, `Connection refused` или окно висит при входе.**
  1. Проверьте IP.
  2. Если сервер только что оплачен — подождите 10–15 минут.
  3. Если всё равно не подключается — попробуйте другой интернет: домашний Wi-Fi вместо мобильного или наоборот. Связь из России с зарубежными серверами иногда блокируется.
- **Связь оборвалась посреди установки** (`Connection reset`, `Broken pipe`). Подключитесь снова (шаг 3) и повторите последнюю команду: всё уже сделанное сохранилось.
- **`Could not get lock` или долгое «жду…».** Сервер сразу после покупки сам ставит обновления. Подождите 5–10 минут и повторите ту же команду.
- **`Permission denied (publickey)` или `Repository not found` на шаге 4.** Ключ не добавлен на GitHub или скопирован не целиком. Повторите шаг 4 с пункта 1: команда снова покажет тот же ключ.
- **`git: command not found`.** Выполните `apt install -y git` и повторите команду.
- **«Сервер не может связаться с Telegram».** Сервер находится в России. Закажите сервер в другой стране и повторите шаги 3–5.
- **«Это не похоже на токен» или «Telegram не принял токен».** Скопируйте токен из сообщения @BotFather целиком и снова запустите команду из шага 5.
- **Внизу экрана двоеточие `:` или `(END)`, и ничего не происходит.** Нажмите латинскую `q`.
- **Любая другая ошибка.** Выделите текст ошибки мышью, нажмите правую кнопку (это «копировать») и пришлите его Claude. С телефона можно прислать снимок экрана.

## Потом: обновление

Когда Claude поменяет расписание или исправит бота, подключитесь к серверу (шаг 3) и выполните:

```
bash /opt/stefa-i-faya/deploy/update.sh
```

Если с новой версией что-то не так, скрипт сам вернёт прежнюю, и бот продолжит работать по-старому.

Полезные команды:
- `systemctl status catbot --no-pager` — работает ли бот: зелёное `active (running)` означает, что да;
- `journalctl -u catbot -n 50 --no-pager` — последние сообщения бота, если нужно разобраться в проблеме.
